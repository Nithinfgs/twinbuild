# Code of Conduct

This project follows the spirit of the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

Be respectful and constructive. Welcome newcomers, assume good intent, and critique code and ideas rather than people. Harassment, discrimination, personal attacks, and publishing others' private information are not acceptable.

## Scope and enforcement

This applies to all project spaces (issues, pull requests, discussions). Maintainers may edit or remove contributions that violate it and may restrict participation. To report a problem, open a private security advisory on the repository or contact the maintainer through their GitHub profile.
